FOTO TEMA BATAKNESE — Budi & Santi

CARA MENGGANTI FOTO
- Cara termudah: timpa file di folder ini memakai NAMA YANG SAMA
  (misalnya ganti mempelai-wanita.jpg dengan foto mempelai wanita
  yang asli, lalu refresh halaman).
- Cara lain: ubah path di js/data.js (bagian "gambar" dan "galeri").

CATATAN
- Foto-foto ini hasil generate AI, BUKAN foto asli mempelai —
  ganti dengan foto asli sebelum undangan dibagikan ke tamu.
- Slot foto yang kosong (path di js/data.js tidak berisi file)
  tampil sebagai bingkai penanda di halaman.
- Kompres foto sebelum diganti (maks. lebar ±1280 px, kualitas
  JPEG ±80) agar ukuran file tetap ringan.
